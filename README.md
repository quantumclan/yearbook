🎓 Digital Yearbook Project
A sleek, responsive, and interactive digital archive built to celebrate our graduating class. 
This project serves as a tribute to my academic journey at the University, where I successfully graduated with a First Class degree.
🚀 Live Demo
https://quantumclan.github.io/yearbook/index.html

📌 Project Overview
The Yearbook Project is a lightweight, frontend-focused web application designed to preserve memories, display student profiles, and showcase gallery highlights. 
By utilizing a static data approach, the application remains fast, secure, and easy to deploy without the need for a complex backend infrastructure.

✨ Key Features
1) Interactive Student Directory: A dynamic list of graduates with detailed profiles.
2) Responsive Photo Gallery: A curated collection of event highlights optimized for mobile and desktop.
3) Smooth UI/UX: Clean transitions and modern layouts built with custom CSS.

🛠️ Tech Stack
HTML5: Structured with semantic elements for better accessibility.

CSS3: Custom styling featuring Flexbox and Grid layouts for responsiveness.

JavaScript (ES6+): Logic for DOM manipulation and interactive components.
